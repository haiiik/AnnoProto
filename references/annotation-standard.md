# 标注标准（Annotation Standard）v2.0.0

本文件是"生成可编辑标注的原型" skill 的完整标注规范。执行 skill 时必读本文件。

v2.0.0 主要变更：标注展示由"每元素右侧浮气泡"改为"右侧统一抽屉浮窗"，按页面区块分组，全页连续编号。

## 标注来源优先级

本标准定义的标注格式作为**兜底规范**。实际生成原型时，标注内容与格式按以下优先级取用：

| 优先级 | 来源 | 适用情况 |
|--------|------|----------|
| 1 | 上游需求文档 | 需求文档中规定的标注文案内容、格式规范（长度、词性、类型、样式等） |
| 2 | 本标准 | 无需求文档，或需求文档未规定的内容与格式 |

具体规则：

- **标注文案内容**（`data-annotate` 主标题、`data-annotate-detail` 详情的具体文字）：优先采用需求文档中的描述；需求文档未涉及该元素时，按本标准第 2 节文案规范自行撰写。
- **标注格式规范**（文案长度上限、词性、类型枚举、视觉样式、区块命名等）：需求文档若有自己的标注风格指南，按需求文档执行；否则按本标准执行。
- **冲突处理**：需求文档与本标准冲突时，以需求文档为准，并在元素清单中标注冲突项供确认。
- **判断与采用**：执行时按"工作区固定路径探测 → 用户消息识别 → 上游 skill 传入 → 主动询问"顺序判断是否存在需求文档；判断到候选后需经用户确认才采用其规范（不直接采用）。详见 SKILL.md"依赖与搭配"章节。

## 0. 挂载约定汇总

| 属性 | 必填 | 作用于 | 说明 |
|------|------|--------|------|
| `data-annotate` | 是 | 可交互元素 | 标注主标题，≤12 字 |
| `data-annotate-type` | 否 | 可交互元素 | 类型枚举，决定圆点/卡片色 |
| `data-annotate-detail` | 否 | 可交互元素 | 标注详情，≤60 字 |
| `data-annotate-section` | 否 | 区块容器 | 区块名，决定抽屉分组标题 |
| `data-page` | 否 | 页面容器 | 页面 id，多页面切换用 |
| `data-page-title` | 否 | 页面容器 | 页面显示名，抽屉标题栏展示 |

示例：

```html
<section data-page="login" data-page-title="登录页">
  <section data-annotate-section="表单区">
    <input data-annotate="邮箱输入框" data-annotate-type="input"
           data-annotate-detail="输入登录邮箱,失焦校验格式">
    <button data-annotate="提交按钮" data-annotate-type="action"
            data-annotate-detail="点击提交表单,成功跳转首页">登录</button>
  </section>
  <div data-annotate-section="底部操作区">
    <a data-annotate="忘记密码" data-annotate-type="link"
       data-annotate-detail="跳转找回密码页">忘记密码</a>
  </div>
</section>
```

## 1. 元素识别规则

### 1.1 必须标注的元素

仅对**可交互元素**或**承载交互语义的容器**进行标注。判定准则：元素在真实产品中会响应用户操作（点击、输入、悬停、拖拽），或其内容需要向开发/设计传达明确的交互意图。

| 元素类别 | HTML 表征示例 | 是否标注 |
|----------|---------------|----------|
| 主操作按钮 | `<button class="btn-primary">` | ✅ |
| 次要/危险按钮 | `<button class="btn-danger">` | ✅ |
| 文本链接 | `<a href>` | ✅ |
| 输入框 | `<input>` `<textarea>` | ✅ |
| 选择控件 | `<select>` | ✅ |
| 复选/单选 | `<input type="checkbox/radio">` | ✅ |
| 图标按钮 | `<button>` 内仅含 `<svg>`/`<img>` | ✅ |
| 导航菜单项 | `<nav>` 下的 `<a>`/`<li>` | ✅ |
| 标签页切换 | `.tab` `.tab-item` | ✅ |
| 可点击卡片 | `.card[data-clickable]` | ✅ |
| 下拉触发器 | `.dropdown-trigger` | ✅ |
| 模态/弹层触发 | 带 `data-modal` 的按钮 | ✅ |
| 表单提交区 | `<form>` 本身 | ✅（标注整体行为） |
| 数据表格行（可操作） | `<tr data-action>` | ✅ |
| 列表数据列（无交互） | `<td>` 数据单元格（仅展示，不可点击） | ✅（标注数据来源） |
| 带规则的标签文本 | `<label>` 内容有固定规则（如自动生成的编号、格式限制） | ✅ |

### 1.2 不标注的元素

| 元素类别 | 理由 |
|----------|------|
| 纯标题/正文 `<h1>`~`<h6>`、`<p>` | 仅展示，无交互 |
| 装饰性图标（无点击） | 不承载交互语义 |
| 容器 `<div>` `<section>`（非点击区） | 结构性，无交互 |
| 标签文本（无固定规则） | 无固定规则，归属于对应输入框的标注 |
| 列表项目符号 | 装饰性 |

### 1.3 边界判定

- **卡片整体可点击 vs 卡片内含按钮**：若整卡可点击，标注卡片；若仅卡片内按钮可点击，标注按钮，不标注卡片。
- **图标 + 文字组合按钮**：视为单一元素，标注一次，挂在最外层 `<button>`。
- **动态加载内容**：为占位区域标注"动态内容区"，类型 `data`。
- **分页器**：每个页码是独立 link 元素，但为避免冗余，仅标注整个分页器容器一次，主标题"分页"，详情说明跳转行为。

## 2. 标注文案规范

### 2.1 主标题（`data-annotate`）

| 规则 | 说明 | 示例 |
|------|------|------|
| 长度 | ≤ 12 个中文字符（或等量英文） | ✅"主操作按钮" ❌"用户登录后点击此按钮提交" |
| 词性 | 名词性短语，不使用完整句子 | ✅"搜索输入框" ❌"这里输入搜索词" |
| 语义 | 概括元素身份，不描述行为 | ✅"删除按钮" ❌"点击删除该项" |
| 唯一性 | 同一页面内尽量不重复；若重复，追加序号 | "筛选标签①""筛选标签②" |

表单字段类（输入框、下拉、文本域、单复选等）与列表数据列元素的主标题取**字段名称**（如"用户名""订单金额"），与详情结构化格式的第一个字段一致。

### 2.2 详情（`data-annotate-detail`）

| 规则 | 说明 | 示例 |
|------|------|------|
| 长度 | ≤ 100 个中文字符 | — |
| 结构 | 操作类："做什么 → 触发什么"；表单/数据类：见下方"结构化格式" | ✅"点击后提交登录表单，成功则跳转首页" |
| 时态 | 描述交互后果，用将来时/祈使语气 | ✅"点击展开二级菜单" |
| 禁止 | 不写实现细节（API、类名）、不写测试用例 | ❌"调用 /api/login 接口" |

#### 结构化格式

表单字段类与列表数据列元素的标注详情采用以下结构化格式：

| 元素类别 | 格式 | 示例 |
|----------|------|------|
| 表单字段（输入框、下拉、文本域、单复选、日期等） | `字段名称 \| 类型 \| 规则/交互逻辑 \| 必填 \| 默认值` | `用户名 \| 文本 \| 长度2-10位，仅中文/英文，超出10位时不允许继续输入 \| 必填 \| 空` |
| 列表数据列（无交互，仅展示） | `字段名称 \| 类型 \| 数据来源 \| 说明` | `订单金额 \| 金额 \| 数据来源：订单系统 \| 展示含税金额，保留2位小数` |

- 主标题（`data-annotate`）取"字段名称"，与格式第一个字段一致。
- **必填字段取值：`必填` / `选填`**（不使用"是/否"）。
- 列表数据列必须标明数据来源（来源系统、接口或上游字段）。
- 按钮、链接等操作类元素不使用结构化格式，保留"做什么 → 触发什么"的普通描述。

### 2.3 区块名（`data-annotate-section`）

| 规则 | 说明 | 示例 |
|------|------|------|
| 长度 | ≤ 20 个中文字符 | ✅"表单区" ❌"用户登录表单区域容器" |
| 词性 | 名词性短语 | ✅"顶部导航区" ✅"底部操作区" |
| 唯一性 | 同一页面内区块名尽量唯一 | 若同名，引擎按出现顺序合并 |
| 来源 | 生成原型时优先从需求文档提取区块名；无需求文档时自行命名 | — |

### 2.4 类型枚举（`data-annotate-type`）

类型决定圆点与卡片左侧色条配色，必须从下表取值：

| 类型 | 适用元素 | 色值 |
|------|----------|------|
| `action` | 按钮、图标按钮、提交操作 | `#2563EB`（蓝） |
| `input` | 输入框、选择器、文本域 | `#7C3AED`（紫） |
| `link` | 文本链接、导航链接 | `#0891B2`（青） |
| `navigation` | 标签页、面包屑、菜单项 | `#EA580C`（橙） |
| `feedback` | 提示、弹层触发、Loading 触发 | `#DC2626`（红） |
| `data` | 数据展示、动态内容区、表格行 | `#16A34A`（绿） |

未指定 `data-annotate-type` 时，引擎默认按 `action` 配色。

## 3. 标注视觉样式规范

> **原型视觉设计规范**（页面底色、排版、线框风/高保真风格、图标、图片占位、组件样式等）**不由本标准规定**，需搭配专门的"设计规范 skill"使用；若无设计规范 skill，则按需求文档或通用线框风自行实现。本节仅规定标注相关的视觉样式（抽屉、卡片、圆点）。

### 3.1 标注抽屉样式（由引擎渲染）

标注统一在页面右侧的固定抽屉浮窗内展示，不再为每个元素单独浮气泡。

| 项 | 值 |
|----|----|
| 抽屉位置 | `position: fixed; top: 0; right: 0` |
| 抽屉宽度 | `320px`（移动端 `88%`，最大 `320px`） |
| 抽屉高度 | `100vh` |
| 抽屉背景 | `#FFFFFF`，左侧 `1px` 边框 `#E5E7EB` |
| 抽屉阴影 | `-2px 0 8px rgba(0,0,0,0.08)` |
| 抽屉头 | 高度自适应，背景 `#F9FAFB`，含页面名 + 标注数 + 保存/标注点显隐/收起按钮 |
| 抽屉体 | 背景浅灰 `#FAFAFA`，纵向滚动 |
| 抽屉收起 | `transform: translateX(100%)`，过渡 `0.25s` |

### 3.2 区块分组样式

| 项 | 值 |
|----|----|
| 分组标题 | `12px` 中粗，左侧 `3px` 色条（默认蓝 `#2563EB`），背景 `#F3F4F6` |
| "其他"分组 | 色条改灰 `#9CA3AF`，文字 `#6B7280`，排在最后 |
| 分组内卡片 | 纵向排列，间距 `6px` |

### 3.3 卡片样式

| 项 | 值 |
|----|----|
| 卡片形状 | 圆角矩形，`border-radius: 6px` |
| 卡片背景 | `#FFFFFF`，边框 `1px #E5E7EB` |
| 卡片左色条 | `3px` 类型色 |
| 卡片内布局 | 序号圆点 + 文本区，间距 `8px` |
| 主标题样式 | `font-size: 13px; font-weight: 500` |
| 详情样式 | `font-size: 12px; color: #4B5563` |
| 悬停态 | `box-shadow: 0 2px 6px rgba(0,0,0,0.08)` |
| 高亮态（被定位时） | `box-shadow: 0 0 0 2px #2563EB` |

### 3.4 序号圆点（页面元素上）

每个被标注元素在其右上角显示一个序号圆点，序号为**全页连续编号**（1, 2, 3…，按抽屉显示顺序，与抽屉卡片序号一致）。

| 项 | 值 |
|----|----|
| 形状 | 圆形，直径 `18px` |
| 背景 | 类型色 |
| 数字 | 白色，`11px`，居中 |
| 边框 | `2px #FFFFFF`（与原型背景区分） |
| 阴影 | `0 1px 3px rgba(0,0,0,0.25)` |
| 悬停态 | `scale(1.15)` |
| 点击行为 | 在抽屉中定位对应卡片并高亮 |

## 4. 交互行为规范

| 行为 | 触发方式 | 结果 |
|------|----------|------|
| 编辑标注文本 | **双击**卡片主标题或详情 | 该文本变为 `contenteditable`，就地编辑 |
| 编辑页面文字 | **双击**页面任意文字（标题、正文、按钮、表格内容等） | 该文字变为可编辑，失焦/Enter 保存，Esc 取消；"保存"按钮导出时保留修改 |
| 保存编辑 | 失焦 / 按 `Enter` | 文本写回 data 属性 |
| 取消编辑 | 按 `Esc` | 恢复原文本 |
| 定位元素 | 点击卡片空白区（非圆点、非编辑文本） | 页面滚动至元素 + 短暂高亮描边 |
| 定位卡片 | 点击页面元素上的序号圆点 | 抽屉自动展开（若收起）并滚动至对应卡片 + 卡片高亮 |
| 保存 | 点击抽屉右上角"保存"按钮 | 回写所有编辑到 data 属性 + 下载单文件 HTML |
| 标注点显隐 | 点击抽屉"隐藏圆点/显示圆点"按钮 | 切换页面元素序号圆点的显隐 |
| 收起抽屉 | 点击抽屉右上角"收起"按钮 | 抽屉移出屏幕，页面右下角显示"展开标注"按钮 |
| 展开抽屉 | 点击页面右下角"展开标注"按钮 | 抽屉移回，展开按钮隐藏 |
| 切换页面 | 原型导航触发 | 引擎监听页面可见性，抽屉自动刷新为当前页标注 |

### 4.1 编辑态视觉

进入编辑态时（双击后），文本外框变为 `1px dashed #2563EB`，背景 `#FFFFFF`，光标定位文本末尾。失焦后写回 data 属性并退出编辑态（`contentEditable` 置回 `false`）。

### 4.2 保存行为

"保存"按钮执行以下操作：

1. 遍历抽屉所有卡片，将 `contenteditable` 文本回写到对应元素的 `data-annotate` / `data-annotate-detail`。
2. 克隆整个 `document.documentElement`。
3. 清理克隆中的引擎 DOM：抽屉（`#__anno_drawer__`）、展开按钮（`#__anno_expand_btn__`）、浮层（`#__anno_layer__`）、元素上的 `.__anno-target` 类与内联高亮样式。
4. 用 `Blob` + `URL.createObjectURL` 触发下载，文件名为原文件名加 `-annotated` 后缀。
5. 按钮文字临时变为"已保存"（绿色），1.5 秒后恢复。

保存后的文件再次打开时，标注文本保持编辑后状态，且仍可继续编辑。

### 4.3 失焦即时回写

为避免编辑后忘记点保存即切换页面导致丢失，卡片文本失焦时也会即时回写到 data 属性。但**下载 HTML 必须点击保存按钮**才会触发。

阶段 1 产出的元素清单应采用以下表格结构，写入临时文件 `element-list.md`：

| 序号 | 页面 | 区块 | 类型 | 元素标识（CSS 选择器或描述） | 主标题 | 详情 |
|------|------|------|------|---------------------------|--------|------|
| 1 | login | 表单区 | action | `.btn-submit` | 提交按钮 | 点击提交表单，成功跳转结果页 |
| 2 | login | 表单区 | input | `input[name=email]` | 邮箱输入框 | 输入登录邮箱，失焦校验格式 |
| 3 | login | 底部操作区 | link | `a.forgot` | 忘记密码 | 跳转找回密码页 |

清单用于：阶段 2 生成 HTML 时逐项挂载 data 属性、阶段 4 校验时核对覆盖率。区块名优先从需求文档提取。

## 6. 多页面与区块处理

### 6.1 多页面结构

多页面原型用单 HTML，每个页面用 `<section data-page="pageId" data-page-title="页面名">` 表示：

```html
<section data-page="login" data-page-title="登录页" class="page"> … </section>
<section data-page="home" data-page-title="首页" class="page" hidden> … </section>
```

- 引擎初始化时识别所有 `[data-page]`，以第一个可见页为当前页。
- 每页独立编号（1, 2, 3…），切换页面后抽屉内容刷新为该页标注。
- 页面切换由**原型自带导航**触发，引擎提供两种支持：
  - 暴露全局函数 `window.__annoGotoPage(pageId)`，原型导航按钮 `onclick` 调用。
  - 用 `MutationObserver` 监听 `[data-page]` 的 `style/class/hidden` 变化，自动刷新抽屉。
- **导航栏样式不由本标准规定**：优先沿用上游需求文档的导航设计；无需求文档时，生成简易导航（页面顶部固定栏，含各页切换按钮，按钮 `onclick` 调用 `window.__annoGotoPage('pageId')`）。
- 单页原型（无 `[data-page]`）按整个 body 为一页处理，无需导航。

### 6.2 区块分组

当前页内按 `data-annotate-section` 区块分组显示：

```html
<section data-annotate-section="表单区">
  <!-- 该区块内的所有 data-annotate 元素归入"表单区"分组 -->
</section>
```

- 引擎扫描当前页所有 `[data-annotate-section]` 容器，按出现顺序生成分组。
- 每个被标注元素归入其最近的 `[data-annotate-section]` 祖先所在分组。
- 不属于任何区块的标注归入"其他"分组。
- `data-annotate-section="全局"` 的标注归入"全局"分组，用于承载跨区块的全局性标注（如页面级说明），排在所有分组最后。
- 分组渲染顺序：普通区块（按出现顺序）→ "其他"分组 → "全局"分组。
- 区块名来源：生成原型时优先从需求文档提取；无需求文档时自行命名。
- 同名区块自动合并为一组。

### 6.3 序号编排

- **按抽屉显示顺序编号**：当前页所有标注按抽屉内渲染顺序（分组顺序 + 组内顺序）连续编号 1, 2, 3…，保证抽屉内序号永远从小到大。
- 序号与 DOM 顺序无关：分组位置固定（普通区块 → 其他 → 全局），序号跟随显示位置重新编排。
- 编号在抽屉卡片与页面元素圆点上同时显示，保持一致。
- 切换页面后编号重新从 1 开始。

### 6.4 响应式

- 移动端（`max-width: 768px`）抽屉宽度改为 `88%`，最大仍 `320px`。
- 序号圆点尺寸不变，避免遮挡元素。
